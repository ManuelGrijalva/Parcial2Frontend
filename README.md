# Frontend - Parcial 2

Aplicación frontend desarrollada con Vue.js y Vuetify para el segundo parcial.

## Tecnologías Utilizadas

- Vue.js 3
- Vuetify 3
- TypeScript
- Vite

## Instalación

1. Clonar el repositorio
2. Instalar dependencias:
```bash
npm install
```
3. Ejecutar en modo desarrollo:
```bash
npm run dev
```
